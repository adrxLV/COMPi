# Learning-path redesign contract

The app retains its existing React/Vite shell, 52 exercise IDs, grading path and Python worker. A `LearningUnit` in `src/contracts.ts` is a focused concept: one teaching screen, one question screen per `exerciseIds` entry, then a completion screen. No duplicated question text or fabricated score. `TeachingStep` is an optional, explicitly Python-verified static visual teaching example, not an execution trace.

`src/content/learning.ts` owns ordered `learningUnits` and mapping to existing exercise IDs; source scope remains Weeks 1-7. Every exercise is assigned to exactly one unit, ordered with introductory reasoning before complex work where the bank permits it. A unit with only one suitable question must not pretend to prove mastery. Week 7 aliases/copies must be marked enrichment if the source does not establish assessment.

`LearnerState` v2 adds `journey` with an optional active `{unitId,screenIndex,startedAt,missed,recovered}` and `completedUnits`. Existing v1 profiles/backups migrate by retaining all earned XP, attempts, completed exercise IDs, drafts and exam data. A migrated unit is complete if all its exercise IDs were previously completed; never wipe old state.

`LessonFlow` props: `{ unit: LearningUnit; exercise?: Exercise; screenIndex: number; answer: Answer; code: string; feedback: 'correct'|'incorrect'|null; hint: boolean; running: boolean; runtime: RuntimeResponse|null; xpEarned: number; answerXpEarned: number; onAnswer(v: Answer): void; onCode(v: string): void; onHint(): void; onSubmit(): void; onAdvance(): void; onBack(): void; onExit(): void; onRetry(): void }`. Contextual review opens the teaching screen locally and returns to the same question without changing persisted screenIndex. `Answer` is imported from `src/assessment/grade.ts`. Exercise screen index 1..unit.exerciseIds.length; index 0 is teaching; index length+1 is completion. UI component exports `ExerciseInput` with the same props as current App-local function, for reuse by Practice and Exam. It owns presentation only, not grading or state writes. Only the parent `App.tsx` owns navigation and grading, and `src/features/lesson/LessonFlow.tsx` owns focused screen presentation. A wrong answer records an attempt, cannot advance directly, and allows retry/revisit teaching; mastery/XP remain governed by existing `applyAttempt`. A later corrected response may move forward but earns no first-try XP. Completion is recorded once at the end of all questions; revisiting is allowed. Other modes preserve their existing interaction contracts.

File ownership: content agent `src/content/learning.ts` and tests; storage agent `src/storage/state.ts` and state tests; lesson UI agent `src/features/lesson/*` only; parent owns `src/contracts.ts`, `src/App.tsx`, shared `src/style.css`, integration, browser QA and documentation status. No agent uses GitHub commands or publishes. No external backend/service.
